# Portfólio · Samuel Rogério

Site de portfólio com meus projetos web e de jogos: **https://srcs-portifolio.vercel.app**

## Tecnologias
- Next.js 15 (App Router) e React 19
- TypeScript
- CSS por componente e animações com AOS
- Deploy contínuo na Vercel

## Como rodar
```bash
npm install
npm run dev
```
Abra http://localhost:3000.

## Organização
- `src/mocks/`: todo o conteúdo do site (início, sobre, projetos, skills)
- `src/components/`: componentes da página
- `public/`: imagens, GIFs dos projetos, vídeo e currículo

Design e base do projeto em parceria com um amigo dev; conteúdo e atualizações por mim.
